# Fourth Wall

A Unity project.

## Requirements

- Unity 2022.3.9f1

## Getting started

1. Clone the repository.
2. Open the project folder in Unity Hub.
3. Select Unity `2022.3.9f1` when prompted.
4. Open the desired scene from `Assets/Scenes` and press Play.

## Project structure

- `Assets/` - game assets, scenes, scripts, audio, animations, and materials.
- `Packages/` - Unity package dependencies.
- `ProjectSettings/` - Unity project configuration.

Generated Unity folders such as `Library/`, `Temp/`, and `Logs/` are excluded from version control.
